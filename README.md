# MusicPlayer

一个用 Qt Quick 和 Qt Multimedia 写的本地音乐播放器。歌曲导入后保存在应用自己的媒体库中，可以离线播放、管理队列和查看同名 LRC 歌词。

## 功能

- 选择多个音频文件或导入文件夹，按标题、歌手、专辑搜索；支持收藏和自定义分类。
- 点击歌曲后，以当前筛选结果建立播放队列；支持顺序播放、单曲循环和随机播放。
- 进度拖动、音量调节、静音、睡眠定时，以及切歌时可选的淡入。
- 歌曲同目录存在同名 `.lrc` 文件时，导入歌曲时一并导入歌词；也会尝试查找同名或 `cover` 封面图片。
- 可切换频谱、背景图和主题色；提供迷你播放器和系统托盘。
- 记住音量、队列和上次播放进度。快捷键：`Ctrl+L` 打开媒体库，`Ctrl+←` / `Ctrl+→` 切歌。

## 构建

需要 C++17 编译器、CMake 3.16 以上和 Qt 6.4 及以上版本的 Core、Gui、Widgets、Quick、Quick Controls 2、Multimedia 模块，以及 QtQuick、QtQuick.Controls、QtQuick.Dialogs 等对应的 QML 运行时模块。音频格式能否播放还取决于操作系统和 Qt Multimedia 后端安装的解码器。

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x/<kit>
cmake --build build --config Release
```

可执行文件位于构建目录；Windows 多配置构建一般位于 `build/Release`。Windows 部署可使用相同 Qt kit 的 `windeployqt --qmldir qml build/Release/MusicPlayer.exe`（路径按构建结果调整）。Linux 需安装与构建版本匹配的 Qt 库、QML 模块、平台插件和多媒体后端。

## 使用

1. 打开**媒体库 → 导入音乐**，选择文件或文件夹。文件夹导入只扫描该目录，不递归扫描子目录。
2. 点击歌曲即可播放。右键歌曲可以收藏、加入队列或从媒体库移除。
3. 点击播放栏的播放模式按钮切换顺序、单曲循环和随机。歌词与封面在导入时从音频文件旁边查找。
4. 关闭窗口退出程序；也可以使用标题栏的最小化按钮或托盘菜单。

媒体库位于用户文档目录下的 `MusicPlayer/`，导入时会复制音频，移除歌曲时删除的是该媒体库内的副本，不会删除原文件。同名文件视为已导入；导入失败时界面会显示失败数量。建议定期备份整个媒体库目录。

频谱分析需要解码整首音频，长音频会占用额外内存，因此默认关闭。文件标签读取与音频格式支持依赖本机多媒体后端；没有读到标签时使用文件名，`歌手 - 歌名` 格式会拆分为歌手和标题。
